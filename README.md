# dsh-balance-widget-fx

Виджет баланса и расходов для DeepSeek Harness (DSH): та же карточка в подвале
сайдбара, но суммы показаны сразу в трёх валютах — **¥, $ и ₽**.

Форк [dsh-balance-widget](https://github.com/LL-cmyk-so/dsh-balance-widget) 0.6.4
(лицензия MIT, автор оригинала — LL-cmyk-so). Номер версии повторяет базовую
версию апстрима.

## Что отличается от оригинала

1. **Три валюты.** Было `¥ 4,21` — стало `¥ 4,21 · $0,59 · 48 ₽`. Во всех местах:
   баланс, последний запрос, «сегодня», узкий футер сайдбара (там короткая пара
   `¥ · $`).
2. **Русский формат чисел** — десятичная запятая, разряды, отброшенные нули
   (`toLocaleString("ru-RU")`) вместо `zh-CN`.
3. **Живые курсы.** Клиент раз в 6 часов забирает
   `https://open.er-api.com/v6/latest/USD` и считает кросс-курсы USD/CNY/RUB.
   Хост-часть отдаёт те же курсы в API полем `fx`. Если сеть недоступна, остаётся
   последний удачный снимок, а на холодном старте — резервные константы
   (1 USD = 81,3 ₽, 1 CNY = 12,16 ₽, зафиксированы 25.10.2026).
4. **Фикс обхода сессий на Windows.** `sessionsRoot()` брала `process.env.HOME`,
   которого в Windows нет: обход шёл по `/.dsh/sessions`, и стоимость всегда
   выходила пустой. Добавлен откат на `process.env.USERPROFILE`.

## Требования

- DSH `>=0.1.2-rc.1 <0.3.0`
- Node `^22.19.0 || >=24.0.0`

## Установка

Сначала убрать оригинал — он и форк регистрируют одну и ту же карточку, и вместе
их ставить нельзя:

```bash
dsh plugin --profile desktop remove dsh-balance-widget
```

Затем поставить форк — с GitHub:

```bash
dsh plugin --profile desktop add github:skyfishitstudio/dsh-balance-widget-fx
```

или из локальной папки:

```bash
dsh plugin --profile desktop add link:/путь/к/dsh-balance-widget-fx
```

После установки перезапустить DSH: клиентский бандл подхватывается только при старте.

## Проверка

В левом нижнем углу сайдбара баланс выглядит примерно так:

```
¥ 4,21 · $0,59 · 48 ₽
```

Если видно только `¥` — загрузился оригинал, проверь, что он удалён из профиля.

## Ограничения

- Курсы берутся с публичного API, без ключа; при блокировке домена будут
  использоваться резервные константы, то есть рублёвые суммы станут приблизительными.
- Валюта отображения не настраивается: показываются все три сразу.
- Сборка не воспроизводится из исходников — в репозитории лежат уже собранные
  `lib/*.js` (как и в апстриме). Правки вносились прямо в бандл.
